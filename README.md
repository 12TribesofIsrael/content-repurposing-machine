# Content Repurposing Service

**Stack:** Repurpose.io (no-code, dashboard-only)
**Build time per client:** 2–3 hours
**Setup fee:** $500–$1,500 | **Monthly retainer:** $97–$297/mo (plus Repurpose.io $49/mo, billed to client)

## What the Client Gets

One piece of content automatically becomes up to 22 pieces distributed across every platform — without touching a single app manually.

**The Content Tree (from 1 short-form video):**
- Full video → YouTube Shorts, FB Page, FB Group, LinkedIn, IG Reels, IG Stories, IG Feed, Pinterest Idea Pins, Twitter/X, Google Drive backup (10 destinations)
- Audio → Podcast (Spotify / Apple / Alexa) + Audiograms across all video platforms (12 destinations)

Every distribution happens through Repurpose.io workflows — point and click, no API setup, no code, no maintenance.

## Proven ROI (use in sales conversations)

- Average creator saves 4–8 hours/week on manual repurposing
- Repurpose.io alone charges $49/mo — client pays you for the custom build + ongoing oversight
- Coaches who post consistently report 2–5x follower growth vs. sporadic posting
- Time savings at $50/hr equivalent = $200–$400/week returned to the client

## What You Need from the Client

- [ ] Primary content source: TikTok? YouTube? Instagram? (determines Repurpose.io source)
- [ ] All destination platform logins (or admin access to connect)
- [ ] Brand voice doc or 3 example posts they like (for caption templates)
- [ ] Posting schedule preference (immediate vs. staggered across the day)
- [ ] Podcast RSS feed (only if audio/podcast distribution is in scope — Enterprise tier)
