# docs/

Setup notes, client-specific configuration, troubleshooting logs, and any
reference material that isn't already covered by the root-level guides
(`setup-sop.md`, `repurpose-io-setup.md`, `content-tree.md`).

## What lives here

- Client-specific brand voice / system-prompt overrides
- Platform API gotchas discovered during real setups
- Token rotation logs (Instagram/Facebook expire every 60–90 days)
- Screenshots and walkthroughs that supplement the root SOPs

## What does NOT live here

- The canonical setup SOP — that stays at the root (`setup-sop.md`)
- Anything client-confidential that shouldn't be committed to git
